# 🍽️ Swiggy Food Orders Analysis — Excel Dashboard Project

An end-to-end data analytics project built entirely in **Microsoft Excel**, analyzing over 197,000 Swiggy food orders across 28 cities in India.

---

## 📌 Project Overview

This project explores real-world food delivery data from Swiggy to uncover trends in ordering behavior, revenue performance, restaurant ratings, and food preferences across major Indian cities. The final output is an interactive Excel dashboard designed for business reporting and storytelling with data.

---

## 📁 File Structure

| File | Description |
|------|-------------|
| `Swiggy_Raw_Data_Excel_.xlsx` | Main Excel file containing raw data, analysis sheets, and the dashboard |

### Sheets Inside the Excel File

| Sheet Name | Description |
|------------|-------------|
| `Swiggy Data` | Raw dataset with 197,430 rows and 14 columns |
| `Sheet1` | Pivot summary — Monthly revenue (Jan to Aug 2025) |
| `DASHBOARD` | Interactive visual dashboard with charts and slicers |

---

## 📊 Dataset Details

| Attribute | Details |
|-----------|---------|
| Total Records | 197,430 orders |
| Time Period | January 2025 – August 2025 |
| Cities Covered | 28 cities |
| States Covered | 28 states |
| Unique Restaurants | 993 |
| Unique Food Categories | 4,972+ |
| Total Revenue Analyzed | ₹5.3 Crore |

### Columns in the Raw Data

| Column Name | Description |
|-------------|-------------|
| `State` | Indian state where the order was placed |
| `City` | City of the order |
| `Order Date` | Date of the order |
| `Day` | Day of the week (Mon, Tue, etc.) |
| `Quarter` | Business quarter (Q1, Q2, Q3) |
| `Week` | Week number of the year |
| `Restaurant Name` | Name of the restaurant |
| `Location` | Area/locality of the restaurant |
| `Category` | Food category (e.g., North Indian Gravy, South Indian Dishes) |
| `Dish Name` | Name of the dish ordered |
| `Veg or Non-Veg` | Whether the dish is vegetarian or non-vegetarian |
| `Price (INR)` | Price of the dish in Indian Rupees |
| `Rating` | Customer rating of the dish (out of 5) |
| `Rating Count` | Number of ratings received |

---

## 🔍 Key Insights

- 📅 **January 2025** recorded the highest monthly revenue at ₹68.25 Lakhs
- 🥗 **71% of orders** were vegetarian (1,39,708 orders)
- 🍖 **29% of orders** were non-vegetarian (57,722 orders)
- 🏙️ Major cities like **Bengaluru, Mumbai, and Hyderabad** dominated order volumes
- 🍽️ South Indian and North Indian cuisines were the most popular categories
- 📈 Consistent revenue between **₹62–68 Lakhs per month** across all 8 months
